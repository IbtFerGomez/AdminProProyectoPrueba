##### Create and set
    >Configure your global identity
        git config --global user.name "Your Name"
        git config --global user.email "your_email@example.com"

    > Check global identity
        git config --list
        git config user.name
        git config user.email

    >Create new repository
        # Initialize the folder as a Git repository
        git init

        # Stage all your files
        git add .

        # Commit the files locally
        git commit -m "Initial commit"

        # Rename the default branch to 'main'
        git branch -M main

        # Link your local project to GitHub (Replace URL with your copied link)
        git remote add origin https://github.com

        # Upload your files to GitHub (use your PAT token if prompted for a password)
        git push -u origin main

    >Subir todo a la rama principal
        git push -u origin master [master. name for the branch]
    
    >Crear una nueva rama de trabajo
        git checkout -b desarrollo
    
##### Branches
    ###Pasos para fusionar main 
    >Cambia a la rama receptora
        git checkout main
    >Fetch all remote branches
        git fetch origin
    >Merge master into your local main
        git merge origin/master
    >Push the consolidated main to GitHub
        git push origin main
    
        Once you have successfully pushed main and it contains all your work, you can clean up the confusion by making main the default branch on GitHub and deleting master.
        Go to your repository on GitHub.com.
        Go to Settings > General (or Branches depending on the UI layout).
        Look for the Default branch section. Click the two arrows icon (Switch to another branch) and change it from master to main.
        Once main is the default, go back to your repository's code tab, click on the branches list (where image_0dc102.png is from), and you will now be able to safely delete the master branch using the trash can icon.
