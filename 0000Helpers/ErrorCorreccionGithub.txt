#####Correccion error github
##Paso 1: Desvincular la carpeta equivocada
    Tu carpeta LocalAdminProSystem ahora cree que es el repositorio de prueba. Vamos a quitarle esa memoria.

    Abre tu explorador de archivos de Windows y ve a C:\Users\WINDOWS\Documents\000 LocalProjects\LocalAdminProSystem.

    Asegúrate de tener habilitada la opción de "Ver elementos ocultos" en la barra superior de Windows.

    Busca una carpeta transparente llamada .git y elimínala. Al hacer esto, la carpeta deja de estar conectada a GitHub y vuelve a ser un directorio normal.

##Paso 2: Preparar la carpeta correcta

    Copia los archivos de tu Drive (I:\...\proyecto prueba) hacia su destino correcto: C:\Users\WINDOWS\Documents\000 LocalProjects\LocalAdminPro.ProyectoPrueba.

    Abre esta carpeta (LocalAdminPro.ProyectoPrueba) en tu VS Code.

    Abre una nueva terminal en VS Code.

##Paso 3: Sobrescribir el error en GitHub
    Como en GitHub subimos el código de la otra app y borramos master, vamos a crear un inicio limpio directamente en main y forzaremos a la nube a aceptarlo, borrando el error anterior. Ejecuta en orden:

    Bash
    git init
    git checkout -b main
    git add .
    git commit -m "Inicialización correcta con los archivos de Proyecto Prueba"
    Ahora, conéctalo a tu repositorio (si te marca un error diciendo que el origin ya existe, cambia add por set-url):

    Bash
    git remote add origin https://github.com/IbtFerGomez/AdminProProyectoPrueba.git
    Finalmente, empuja los archivos usando -f (force). Esto le dice a GitHub: "Ignora lo que tienes, esta es la única verdad ahora":

    Bash
    git push -f origin main
